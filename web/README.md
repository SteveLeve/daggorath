# Web build (stopgap)

The SDL3 desktop shell (`src/platform/sdl_app.cpp`) compiled to WebAssembly
as an installable landscape PWA, set up for a static-assets-only Cloudflare
Worker. Why and how: [ADR-0011](../docs/adr/0011-web-stopgap-delivery.md).

**Local only; do not deploy.** `dod.wasm` contains the extracted original
tables (licensing Q4). Serving it anywhere other people can reach is
distribution, which waits until `docs/licensing/README.md` records answers
to Q1, Q2, Q4 and Q5, or a private deployment behind an access gate
(ADR-0011 decision 6). CI only checks that the target builds.

## Build and run

```sh
. <emsdk>/emsdk_env.sh       # emsdk 6.0.10 is known to work
make web                     # -> web/dist (gitignored)
cd web && npx wrangler@4.50.0 dev   # http://localhost:8787
```

`?layout=phone` or `?layout=tablet` overrides the automatic choice; otherwise
screens wider than 1.6:1 get the phone layout.

- **Restart after rebuilding.** `wrangler dev` can serve a stale file after a
  rebuild (it answered 304 for a changed `dod.wasm`), so restart it after
  `make web`.
- **Phones on the LAN.** `npx wrangler@4.50.0 dev --ip 0.0.0.0` lets a phone on the
  LAN play. The service worker (offline cache, full install) needs HTTPS or
  `localhost`, so it does not run there.
- **Local cache files.** `wrangler dev` writes local cache files, including
  network and location metadata, under `web/node_modules/` and
  `web/.wrangler/`. Both are gitignored; keep them that way.

## Files

| Path | Role |
|---|---|
| `public/index.html` | Page shell: full-window canvas, `Module` setup, service-worker registration, portrait notice |
| `public/manifest.webmanifest` | Standalone, landscape PWA manifest |
| `public/sw.js` | Cache-first offline cache; `make web` stamps the build hash into its name |
| `public/_headers`, `public/robots.txt` | Response headers (noindex, wasm MIME type, revalidation) and crawler block |
| `wrangler.jsonc` | Worker config: assets from `dist/`, no script |
| `../tools/web/make_icons.py` | Draws the original icons at build time |
| `../src/platform/web/web_storage.cpp` | localStorage backend for saves, menu slots and preferences (ADR-0011 decision 7) |
| `../tools/web/storage-test.mjs` | `make web-test`: headless-Chrome storage test, including forced write and read failures |
| `dist/THIRD_PARTY_NOTICES.txt` | Generated by `make web` from emsdk's licence texts (ledger §6) |
